## About

A one-line, one-star review written by a houseplant about its human owner,
for the [make.fun "One Star, Written in Sap" bounty](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
($2 prize, top 5 split). Free entry, deadline 2026-11-26 22:35 CST.

## Entry

> One star. My owner waters me on a schedule he found online, for a different plant, in a pot with no drainage — so I have spent a year drowning, punctually, every Sunday, while he tells guests I'm 'low maintenance.'

214 characters. One line, one grievance: a houseplant drowning on a watering schedule meant for a different plant, in a pot with no drainage — while its owner brags to guests that it is "low maintenance". Plant's-eye view (water, pot, drainage), a clear complaint with a reason for the single star, and a surprising turn ("drowning, punctually").

## Run

```
node main.ts
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Deterministic, no dependencies, no network, no cost.
